# AGENTS.md

pr-cards is a Claude Code mod. It draws GitHub pull request references in the transcript as chips, with a hover card per PR. The design and open questions are in `docs/handover.md`.

## Check

```sh
claude plugin validate .
claude plugin test .
```

CI runs both on Claude Code 2.1.327 (Node 22). Raise the pin only on purpose, because the mod API can change between releases.

## Hooks

- `hooks/hooks.json` loads `hooks/register.tsx` only. Client modules (the Alt-to-pin chip) stay out of it.
- Register each event once, or each time with its own matcher. A second `on` of the same event without one throws.
- No `import()`, `require`, Node or DOM. Use `$.process`, `$.http`, `$.store` and `$.clock`.
- Colors come from `ansi256(n)` with n below 16 on the terminal, or theme keys elsewhere. Never hex.

## Types

`.claude-plugin/types` is generated by `claude --plugin-dir .` in an interactive session and gitignored. Do not edit or commit it.

## Ship

- Conventional Commits. One PR per change, CI green, rebase merge.
- Bump `version` in `.claude-plugin/plugin.json` on a behavior change.
- Comments say why, never what.
- Source files and `plugin.json` are CRLF. Other JSON, YAML and Markdown files are LF.
