# Security policy

## Supported versions

Only the latest release gets fixes. It is the `latest` tag of `@accodev/pullywog` on npm and the newest `pullywog--v*` tag on GitHub.

## Reporting a vulnerability

Report it privately through GitHub: open the repository's **Security** tab and click **Report a vulnerability**. Do not open a public issue.

A first answer comes within 7 days. A fix for a confirmed report ships as a patch release, and the advisory is published with it.
